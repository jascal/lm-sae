# Talema

A constructed language whose grammar is three exceptionless rules converting to and from the universal
Type–Link–Merge form of [docs/UNIVERSAL_GRAMMAR.md](../docs/UNIVERSAL_GRAMMAR.md). Its vocabulary is drawn from
English, German and Spanish, weighted by frequency. Full specification: [docs/CONLANG.md](../docs/CONLANG.md).

| file | what |
|---|---|
| `lexicon.tsv` | 6,000 concepts: root, class, en/de/es source words, frequency weight, root tier, source similarity (generated by `scripts/conlang/lexicon.py`) |
| `core.tsv` | the hand-aligned closed-class core (articles, pronouns, prepositions, conjunctions, auxiliaries) |
| `../dl/conlang/linearize.dl` | the grammar, as Soufflé Datalog (includes `dl/tlm/tlm.dl`) |
| `../scripts/conlang/conlang.py` | translate / round-trip gate / comparison driver |
